    Median time per page fault in the Python simulator, which times every fault. Compare policies with each other, not with a kernel.

      How the learned policy decides

      A logistic regression trained offline to imitate Belady's OPT. At every page fault it scores a few sampled resident pages and evicts the one least likely to be needed soon.

      01Pipeline

        02Feature weights

        Positive weight: a larger value makes the page more likely to be evicted. Negative weight: a larger value keeps the page. Features are log-scaled, so the weights are comparable.
